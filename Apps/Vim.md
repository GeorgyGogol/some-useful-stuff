# Текстовый редактор Vim

Раздел, посвященный великолепному текстовому редактору Vim.

Официальный сайт: https://www.vim.org

Год выхода: 2 ноября 1991 года

## Синопсис

> Vim is a highly configurable text editor built to make creating and changing any kind of text very efficient. It is included as "vi" with most UNIX systems and with Apple OS X.

Програма как минимум используется git как редактор коммитов по-усолчанию. Так что лучше хоть немного про неё знать.

## Открытие файла

В случае редактирования сообщения коммита, git сам откроет vim в консоли, если не был настроен другой текстовый редактор.

Чтобы открыть текстовыйй файл в vim:

```sh
vim fileName
```

Заклинание приводит к открытию файла fileName.

Как закрыть можно посмотреть [тут](#управление)

## Режимы работы

Vim поддерживает несколько режимов работы:

### Просмотр

Обычно, запускается при открытии.

В этом режиме можно смотреть или командовать программой.

### Редактирование

Для перехода в этот режим нужно нажать клавишу "a" или "i".

Чтобы выйти из него (после внесения изменений), достаточно нажать Esc.

Этот режим позволяет редактировать открытый файл

## Управление

Управление редактором происходит в режиме просмотра, с предворительным вводом ":". Ниже приведена таблица команд с мнемоникой для запоминания. Фактически, это первые буквы того, что нужно сделать.

| Команда | Мнемоника    | Что делает                   |
|---------|--------------|------------------------------|
| :q!     | quit (now!)  | Выйти без сохранения         |
| :w      | write        | Сохранить изменения          |
| :wq     | write'n'quit | Сохранить и закрыть редактор |

Если файл был изменен, просто выйти не получится: редактор просто так не даст выйти. Нужно или сохранить изменения, или выйти "принудительно".
