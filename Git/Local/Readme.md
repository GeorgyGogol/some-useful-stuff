# Локальный репозиторий

Репозиторий (рабочая копия) на компьютере. Вообще, локальный репозиторий состоит из двух частей - рабочая директория и директория ".git". Рабочая директория соответствует текущей распакованной ветке (HEAD репозитория), а в .git хранится информация о репозитории в целом.

## Инициализация

```sh
git init
git init --bare
```

1. Инициализация репозитория в текущей директории
2. Создание "голого" репозитория в текущей директории, без рабочей директории. Т.е. получаем что-то типа репозитория-сервера, который может только хранить файлы. Об этом можно узнать [тут](LocalRepo.md)
