# Локальный репозиторий

Репозиторий (рабочая копия) на компьютере. Вообще, локальный репозиторий состоит из двух частей - рабочая директория и директория ".git".
Рабочая директория соответствует текущей распакованной ветке (HEAD репозитория), а в .git хранится информация о репозитории в целом.

## Настройка

После установки необходимо выполнить настройку (конфигурирование) git - установить пользователя, его адрес, под которым будет выполняться работа.
Выполняется это с помощью следующих команд:

```sh
git config <--global> user.name <name>
git config <--global> user.email <email>
git config user.name
git config user.email
```

1. Устанавливает имя пользователя
2. Устанавливает адрес электронной почты пользователя
3. Отображает установленное имя пользователя в текущем репозитории
4. Отображает установленный адрес электронной почты пользователя в текущем репозитории

* Опция "--global" выполняет настройку в глобальном плане - для всех репозиториев без дополнительных переопределений; без указания этой опции изменения будут локальными, только для текущего репозитория

## Инициализация

```sh
git init
git init --bare
```

1. Инициализация репозитория в текущей директории
2. Создание "голого" репозитория в текущей директории, без рабочей директории. Т.е. получаем что-то типа репозитория-сервера, который может только хранить файлы. Об этом можно узнать [тут]()
