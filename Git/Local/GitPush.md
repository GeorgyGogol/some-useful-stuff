# Отправка изменений

Отправка изменений на удаленный сервер

## Синопсис

Команда для отправки изменений на удаленный сервер:

```sh
git push <options> <remote-name>
git push <options> <remote-name> <branch-name>
git push -d <remote-name> <branch-name>
```

1. Отправить текущую ветку на удаленный репозиторий
2. Отправить ветку branch-name на удаленный репозиторий
5. Удалить в удаленном репозитории ветку

## Немного про опции

| Опция              | Значение                                                |
| ------------------ | ------------------------------------------------------- |
| -f, --force        | Принудительно применить изменения                       |
| -q, --quiet        | Сделать это "тихо" - без вывода информации о выполнении |
| --tags             | Отправить метки локального репозитория                  |
| -u, --set-upstream | Установить отслеживаемую ветку для отправляемой ветки   |
| -d, --delete       | Удалить отправляемую ветку в удаленном репозитории      |
| --all              | Отправить все ветки локального репозитория              |
