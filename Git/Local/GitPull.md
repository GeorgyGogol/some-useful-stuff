# Получение изменений

Пользование команды получение актуальных изменений из удаленного репозитория.

## Синопсис

В процессе разработки в команде возникает потребность "подтянуть" изменения, которые были сделаны другими разработчиками. Для этого существует два пути и три команды: git pull и git fetch. Этому и посвящен текущий раздел.

## Простое получение изменений

Чтобы просто получить изменения существует комбинированная команда:

```sh
git pull <remote_name>
```

* remote_name - название удаленного репозиотрия. Если его не указывать, то будет взято значение origin.

## Немного сложнее

git pull является автоматическим объединением двух команд:

1. git fetch - "подтягивание" изменений из удаленного репозитория
2. git merge <remote_name>/<current_branch_name> - выполнение слияние с текущей веткой на удаленном репозитории

## Команда fetch

Выполняет загрузку всех изменений из удаленного репозитория

```sh
git fetch <remote_name>
```

* remote_name - название удаленного репозитория

Если что-то пошло не так, то результат выполнения команды вернет значение, отличное от 0. В основном получалось получить код 128 при недоступности удаленного репозитория (ошибка соединения). Соответственно, это же справедливо и для команды git pull, так как она является объединением этой команды с командой слияния
