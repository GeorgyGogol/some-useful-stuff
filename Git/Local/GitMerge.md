# Слияние изменений

Команда для слития (синхронизациии) изменений с другой ветки.

## Синопсис

Команда для "влития" изменений с другой ветки в текущую. Заклинание, для обычного случая выглядит так:

```sh
git merge <options> <from_branch_name>
```

## Немного про опции


| Опция          | Значение                                              |
| -------------- | ----------------------------------------------------- |
| --ff-only      | Применить стретегию fast-forward без создания коммита |
| --no-commit    | Не создавать коммит слияния автоматически             |
| --squash       | Объединить изменения в единый коммит                  |
| -s, --strategy | Использовать определенную стратегию слияния           |
| --abort        | Прерывает текущую операцию и отменяет изменения       |

## Конфликты слияния

Иногда, в процессе "слития" изменений, могут возникнуть конфликты - изменения на одном участке кода. Так как git не является самой умной системой, наткнуться на такую ситуцию достаточно просто. В случае конфликта появляются соответствующие сообщения "CONFLICT:" в файлах с конфликтующими изменениями.

Конфлитные изменения разделяются с помощью строк "<<<<<", "=====" и ">>>>>" (фактическое количество может отличаться), разделяющее изменения в текущей и подливаемой версией соответственно.

Для выполнения мержа абсолютно ВСЕ конфликты должны быть разрешены.
