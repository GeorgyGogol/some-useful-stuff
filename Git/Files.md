# Файлы в репозитории

В этом разделе собрана информация по физическим файлам, используемым СКВ Git

## .gitignore

Шаблоны путей и названий, которые будут игнорироваться

Шаблон файла, заставлюящий игнорировать директорию, кроме файла игнорирования:

```txt
*
!.gitignore
```

## .gitkeep

Пустой файл, наличие которого гарантирует попадание директории в индекс и отслеживание

## .gitmodules

Файл с описанием подмодулей репозитория. Обычно содержит информацию о: 

1. Название
2. Нахождение в репозитории
3. URL или адрес основного репозитория
4. Ветка, используемая в текущем репозитории

# Файлы в папке .git

В целом наличие этой папки говорит о наличии репозитория в текущем месте. В ней хранятся файлы:

1. Необходимые для работы
2. Определяющие поведение (хуки)
3. Временные

## COMMIT_EDITMSG

Файл, создающийся во время операции commit с текстом, который будет использован в коммите

## Файл блокирования индекса

Наличие файла index_lock говорит о том, что в настоящее время индекс репозитория используется и его изменение не доступно. Но иногда... Его приходится удалять в ручную.

## config

Файл локальной конфигурации репозитория. Этот файл переопределяет для репозитория глобальные настройки.

Помимо настроек, содержит информацию об удаленных репозиториях (remote) и ветках (branch).

## FETCH_HEAD

Содержит хэш коммита 

Я не знаю чего.

## ORIG_HEAD

Содержит хэш коммита головной ветки удаленного репозитория

## description

Содержит описание репозитория
