# Удаленный репозиторий

Репозиторий, который находится где-то кроме твоего компьютера. Обычно это так называемый bare-репозиторий, который находится на удаленном компьютере или сервере. Под понятием "Сервер" подразумевается хранилище репозиториев и, как правило, представляет из себя (мою шизу) специализированное ПО. Однако, сервером вполне может выступать и обычная FTP директория (в общем доступе).

## Инициализация нового репозитория

Чтобы инициализировать такой репозиторий, нужно произнести вслух заклинание:

```sh
git init --bare
```

После чего в текущей директории будет создан "голый" репозиторий без рабочей копии.

Получение выполняется командами:

## Получение существующего

```sh
git clone <Server:><Path><.git>
git clone file://<Repo-path>
```

1. Получение сетевого репозитория по http (если поддерживается), https, ssh
   * Server - это удаленный сервер
   * Path - Путь
   * .git - Опционально
2. Получение репозитория из определенной директории

## Неполное получение существующего

```sh
git clone <repo> --single-branch
git clone -b <branchName> --depth <nCommits> <repo>
```

1. --single-branch получает текущую HEAD ветку репозитория repo
2. Флаг -b или --branch определяет название получаемой ветки - branchName
3. --detpth ограничивает количество получаемых коммитов числом nCommits ветки branchName

Предположительно, для получения дополнительных веток нужно выполнить:

```sh
git remote add -t $BRANCH -f origin $REMOTE_REPO
```
