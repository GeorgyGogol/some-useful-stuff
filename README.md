Для написания пользовался Obsidian и MS VS Code. Плюсы каждого текстовика ниже:

| Obsidian                  | MS VS Code                         |
| ------------------------- | ---------------------------------- |
| Стильно выглядит          | Тривиально работает                |
| "Шаблоны" заметок         | Автоматически обновляет содержание |
| Хорошо дружит с таблицами | У вас скорее всего он есть         |
| Можно смотреть с телефона |                                    |

Да-да, такие стильные и красивые таблицы делает Обсидиан. Но для него нужно провести несколько настроек:

1. Директория с шаблонами (для разработки) - директория "_resources"
2. Пути ссылок - относительные

Еще стоит отметить, что для совместимости с Обсидиан я не делаю переход на новую строку при начале предложений. Программа не делает различий между разрывом и двойным разрывом строки. Если НЕОЖИДАННО я найду решение этой проблемы (или кто-то где-то подскажет), то вместо этой строки будет еще один пункт настроек.

# Branches

* master - Основная ветка, содержит только release x.x.x
* dev - Ветка с основной рабочей версией
* dev_mobile - Ветка с рабочей версией на телефоне
* dev_mac - Ветка с рабочей версией на маке
* ForFactorio - Изменения, касающиеся чертежей Факторио
* ForCmake - Изменения, касающиеся Смакэ
* patch - временная ветка для сбора патча для master

Ожидающиеся изменения после 0.5:

* master - Основная ветка, содержит только release x.x.x
* dev/main - Ветка с основной рабочей версией
* dev/mob/main - Ветка с рабочей версией на телефоне
* dev/< theme > -  Ветка, посвященная определенной теме
* patch/< patch name > - для разработки и сбора патчей

После влития в общую ветку (dev или master) ветка с темой удаляется

Если тут есть кто-то, кроме GGogol, то ему нужно делать своё поддерево веток...
